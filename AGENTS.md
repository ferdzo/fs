# Agent Guidelines

## Git commit messages

- Never add AI/attribution trailers: no `Co-authored-by:` from tools, no `Ultraworked with ...` footers.
- Plain imperative subject line, matching existing repo style (e.g. "Reject unsupported aws-chunked uploads").

## Releases

- Tags are cut from `develop` (pre-1.0); do not tag from `master`.
